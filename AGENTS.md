# Project 5 instructions

- Work only on the approved Project 5 milestone; do not begin later milestones implicitly.
- Keep document identity, evidence, facts, findings, calculations, and human decisions as separate
  boundaries. Unknown values must remain unknown rather than becoming zero.
- Preserve workstream, entity, currency, unit, period, evidence, and derivation lineage.
- Keep deterministic finance logic separate from AI-assisted classification, extraction, and
  interpretation. AI output is always a candidate until supported and reviewed.
- Do not import private implementation modules from Projects 1–4. Adapt stable concepts behind
  Project 5 contracts until a genuinely shared package has multiple concrete consumers.
- Use Python 3.11+, a `src` layout, frozen dataclasses for core value objects, and narrow typed
  protocols at external boundaries.
- Keep source documents, secrets, caches, generated indexes, and large datasets out of Git.
- Run Ruff, mypy, and pytest before reporting a milestone complete.
